Idée d'une commande pour écrire interactivement du texte ?

Pour ajouter une **commande interactive** qui permet d'écrire du texte ligne par ligne (comme `nano` ou `vim` en mode simplifié), tu peux implémenter une commande appelée **`edit`** ou **`write`**.

---

## **📌 Concept de la Commande `edit`**
1. **Lancement** :
   L'utilisateur tape `edit <nom_du_fichier>` pour démarrer l'édition.
   Exemple : `edit monFichier.txt`

2. **Mode Édition** :
   - Le terminal passe en **mode édition** : l'utilisateur peut saisir du texte ligne par ligne.
   - Chaque ligne est ajoutée au fichier **au fur et à mesure**.
   - Pour **quitter et sauvegarder**, l'utilisateur tape une commande spéciale (ex: `:wq` comme dans `vim`).
   - Pour **quitter sans sauvegarder**, il tape `:q`.

3. **Affichage** :
   - Pendant l'édition, le terminal affiche un **prompt spécial** (ex: `EDIT> `) pour indiquer qu'il est en mode édition.
   - Le texte saisi est affiché en temps réel.

4. **Gestion des Erreurs** :
   - Si le fichier n'existe pas, il est créé automatiquement.
   - Si l'utilisateur essaie de quitter sans sauvegarder, un message de confirmation peut être affiché.

### **1. Ajouter la Classe `EditCommand.java`**
Crée une nouvelle classe dans le package `fr.terminal.commands` :

```java
package fr.terminal.commands;

import fr.terminal.FileSystem;
import java.util.Scanner;

/**
 * Commande 'edit' : permet d'écrire interactivement du texte dans un fichier.
 * Mode édition : l'utilisateur saisit du texte ligne par ligne.
 * Pour sauvegarder et quitter : ':wq'
 * Pour quitter sans sauvegarder : ':q'
 */
public class EditCommand implements Command {
    private FileSystem fileSystem;
    private Scanner scanner;

    public EditCommand(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
        this.scanner = new Scanner(System.in);
    }

    @Override
    public String execute(String[] args) {
        if (args.length == 0) {
            return "Usage: edit <filename>";
        }

        String fileName = args[0];
        StringBuilder content = new StringBuilder();

        // Si le fichier existe déjà, on charge son contenu
        if (fileSystem.exists(fileName)) {
            content.append(fileSystem.cat(fileName));
        }

        // Message d'entrée en mode édition
        StringBuilder output = new StringBuilder();
        output.append("Édition du fichier '").append(fileName).append("'.\n");
        output.append("Tapez ':wq' pour sauvegarder et quitter, ':q' pour quitter sans sauvegarder.\n");
        output.append("EDIT> ");

        // Simuler l'entrée utilisateur (à adapter pour Swing)
        // Dans une vraie implémentation Swing, il faudrait gérer les entrées via l'UI
        System.out.print(output.toString());

        String line;
        while (true) {
            line = scanner.nextLine();
            if (line.equals(":wq")) {
                fileSystem.echo(fileName, content.toString());
                return "Fichier '" + fileName + "' sauvegardé.";
            } else if (line.equals(":q")) {
                return "Édition annulée.";
            } else {
                content.append(line).append("\n");
            }
            System.out.print("EDIT> ");
        }
    }
}
```

### **2. Adapter pour Swing**
Dans une **interface Swing**, tu ne peux pas utiliser `Scanner` car l'entrée utilisateur passe par le `JTextField`. Il faut donc :
- **Désactiver le champ de commande principal** pendant l'édition.
- **Ajouter un nouveau champ de saisie** pour le mode édition.
- **Gérer les entrées** via des écouteurs d'événements.

#### **Modifications dans `TerminalEmulator.java`**
Ajoute ces méthodes et champs :

```java
// Dans la classe TerminalEmulator
private boolean isEditing = false;
private String currentEditFile;
private StringBuilder editBuffer;

// Dans le constructeur, après l'initialisation de commandParser :
editBuffer = new StringBuilder();

// Modifie la méthode executeCommand pour gérer le mode édition
private void executeCommand() {
    String command = inputField.getText().trim();
    inputField.setText("");

    if (command.isEmpty()) {
        printPrompt();
        return;
    }

    appendToOutput(command + "\n");

    if (isEditing) {
        handleEditInput(command);
        return;
    }

    if (command.startsWith("edit ")) {
        startEditMode(command.substring(5).trim());
        return;
    }

    String output = commandParser.execute(command, currentDirectory);
    appendToOutput(output + "\n");

    if (command.startsWith("cd ")) {
        currentDirectory = fileSystem.getCurrentDirectory();
    }

    printPrompt();
}

// Démarre le mode édition
private void startEditMode(String fileName) {
    isEditing = true;
    currentEditFile = fileName;
    editBuffer.setLength(0); // Vide le buffer

    if (fileSystem.exists(fileName)) {
        editBuffer.append(fileSystem.cat(fileName));
    }

    appendToOutput("Édition du fichier '" + fileName + "'.\n");
    appendToOutput("Tapez ':wq' pour sauvegarder et quitter, ':q' pour annuler.\n");
    printEditPrompt();
}

// Gère les entrées en mode édition
private void handleEditInput(String input) {
    if (input.equals(":wq")) {
        fileSystem.echo(currentEditFile, editBuffer.toString());
        appendToOutput("Fichier '" + currentEditFile + "' sauvegardé.\n");
        endEditMode();
    } else if (input.equals(":q")) {
        appendToOutput("Édition annulée.\n");
        endEditMode();
    } else {
        editBuffer.append(input).append("\n");
        appendToOutput("EDIT> " + input + "\n");
        printEditPrompt();
    }
}

// Termine le mode édition
private void endEditMode() {
    isEditing = false;
    currentEditFile = null;
    printPrompt();
}

// Affiche le prompt d'édition
private void printEditPrompt() {
    try {
        StyledDocument doc = outputArea.getStyledDocument();
        Style style = doc.addStyle("EditPrompt", null);
        StyleConstants.setForeground(style, Color.YELLOW);
        StyleConstants.setBold(style, true);
        doc.insertString(doc.getLength(), "EDIT> ", style);
    } catch (BadLocationException e) {
        e.printStackTrace();
    }
}
```

## **📌 1. Architecture des Modes d'Édition**
On va créer :
- Une **interface `TextEditor`** pour définir le contrat des éditeurs.
- Deux implémentations : `VimEditor` et `NanoEditor`.
- Une **commande `edit`** qui délègue à l'éditeur sélectionné (par défaut : `nano`).

---

### **📄 Interface `TextEditor`**
```java
package fr.terminal.editors;

/**
 * Interface pour les éditeurs de texte (vim, nano, etc.).
 */
public interface TextEditor {
    /**
     * Lance l'édition d'un fichier.
     * @param fileSystem Le système de fichiers.
     * @param fileName Le nom du fichier à éditer.
     * @return Le contenu final du fichier (null si annulé).
     */
    String edit(FileSystem fileSystem, String fileName);

    /**
     * Retourne le nom de l'éditeur.
     */
    String getName();
}
```

## **📄 Implémentation de `NanoEditor`**
Simule le comportement de base de `nano` :
- Saisie ligne par ligne.
- `:wq` pour sauvegarder et quitter.
- `:q` pour quitter sans sauvegarder.
- `Ctrl+O` (simulé par `:save`) pour sauvegarder sans quitter.

```java
package fr.terminal.editors;

import fr.terminal.FileSystem;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

/**
 * Éditeur de texte inspiré de nano.
 */
public class NanoEditor implements TextEditor {
    private Scanner scanner;

    public NanoEditor() {
        this.scanner = new Scanner(System.in);
    }

    @Override
    public String edit(FileSystem fileSystem, String fileName) {
        StringBuilder content = new StringBuilder();
        if (fileSystem.exists(fileName)) {
            content.append(fileSystem.cat(fileName));
        }

        System.out.println("--- Nano: Édition de '" + fileName + "' ---");
        System.out.println("Commandes: :wq (sauvegarder et quitter), :q (quitter), :save (sauvegarder)");
        System.out.println("Tapez votre texte (une ligne à la fois):");

        List<String> lines = new ArrayList<>();
        if (!content.toString().isEmpty()) {
            for (String line : content.toString().split("\n")) {
                lines.add(line);
                System.out.println(line);
            }
        }

        while (true) {
            System.out.print("nano> ");
            String input = scanner.nextLine();

            if (input.equals(":wq")) {
                return String.join("\n", lines);
            } else if (input.equals(":q")) {
                return null; // Annuler
            } else if (input.equals(":save")) {
                fileSystem.echo(fileName, String.join("\n", lines));
                System.out.println("Fichier sauvegardé temporairement.");
            } else {
                lines.add(input);
            }
        }
    }

    @Override
    public String getName() {
        return "nano";
    }
}
```

### **📄 Implémentation de `VimEditor`**
Simule un sous-ensemble de `vim` :
- Mode **commande** (par défaut) et mode **insertion** (`i` pour entrer en mode insertion).
- `:wq` pour sauvegarder et quitter.
- `:q!` pour quitter sans sauvegarder.
- `Esc` pour revenir en mode commande (simulé par `:esc`).

```java
package fr.terminal.editors;

import fr.terminal.FileSystem;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

/**
 * Éditeur de texte inspiré de vim (simplifié).
 */
public class VimEditor implements TextEditor {
    private Scanner scanner;
    private boolean insertMode = false;

    public VimEditor() {
        this.scanner = new Scanner(System.in);
    }

    @Override
    public String edit(FileSystem fileSystem, String fileName) {
        StringBuilder content = new StringBuilder();
        if (fileSystem.exists(fileName)) {
            content.append(fileSystem.cat(fileName));
        }

        System.out.println("--- Vim: Édition de '" + fileName + "' ---");
        System.out.println("Mode: COMMANDE | Tapez 'i' pour passer en mode insertion");
        System.out.println("Commandes: :wq (sauvegarder et quitter), :q! (quitter sans sauvegarder), :esc (mode commande)");

        List<String> lines = new ArrayList<>();
        if (!content.toString().isEmpty()) {
            for (String line : content.toString().split("\n")) {
                lines.add(line);
            }
        }

        int currentLine = lines.size() - 1;
        if (currentLine < 0) currentLine = 0;

        while (true) {
            if (insertMode) {
                System.out.print("vim [INSERT] > ");
            } else {
                System.out.print("vim [COMMAND] > ");
            }

            String input = scanner.nextLine();

            if (insertMode) {
                if (input.equals(":esc")) {
                    insertMode = false;
                } else {
                    // En mode insertion, ajouter à la ligne courante
                    if (currentLine >= lines.size()) {
                        lines.add(input);
                    } else {
                        lines.set(currentLine, lines.get(currentLine) + input);
                    }
                    currentLine++;
                }
            } else {
                // Mode commande
                if (input.equals("i")) {
                    insertMode = true;
                } else if (input.equals(":wq")) {
                    return String.join("\n", lines);
                } else if (input.equals(":q!")) {
                    return null; // Annuler
                } else if (input.equals(":esc")) {
                    // Déjà en mode commande, ignorer
                } else {
                    System.out.println("Commande inconnue. Tapez 'i' pour éditer, ':wq' pour sauvegarder, ':q!' pour quitter.");
                }
            }
        }
    }

    @Override
    public String getName() {
        return "vim";
    }
}
```

## **📄 Mise à Jour de `EditCommand`**
La commande `edit` va maintenant :
- Accepter un argument optionnel pour choisir l'éditeur (`--vim` ou `--nano`).
- Par défaut, utiliser `nano`.

```java
package fr.terminal.commands;

import fr.terminal.FileSystem;
import fr.terminal.editors.NanoEditor;
import fr.terminal.editors.TextEditor;
import fr.terminal.editors.VimEditor;
import java.util.HashMap;
import java.util.Map;

/**
 * Commande 'edit' : lance un éditeur de texte (nano ou vim).
 * Usage:
 *   edit <filename>          # Utilise nano par défaut
 *   edit --nano <filename>   # Force nano
 *   edit --vim <filename>    # Force vim
 */
public class EditCommand implements Command {
    private FileSystem fileSystem;
    private Map<String, TextEditor> editors;

    public EditCommand(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
        this.editors = new HashMap<>();
        editors.put("nano", new NanoEditor());
        editors.put("vim", new VimEditor());
    }

    @Override
    public String execute(String[] args) {
        if (args.length == 0) {
            return "Usage: edit [--nano|--vim] <filename>";
        }

        String editorType = "nano"; // Par défaut
        String fileName;

        if (args[0].equals("--nano") || args[0].equals("--vim")) {
            editorType = args[0].substring(2); // Enlève les "--"
            if (args.length < 2) {
                return "Usage: edit [--nano|--vim] <filename>";
            }
            fileName = args[1];
        } else {
            fileName = args[0];
        }

        TextEditor editor = editors.get(editorType);
        if (editor == null) {
            return "Éditeur inconnu: " + editorType;
        }

        String result = editor.edit(fileSystem, fileName);
        if (result == null) {
            return "Édition annulée pour '" + fileName + "'.";
        } else {
            fileSystem.echo(fileName, result);
            return "Fichier '" + fileName + "' sauvegardé avec " + editor.getName() + ".";
        }
    }
}
```

## **📌 2. Commande `run` pour Exécuter des Scripts**
Un **script** est un fichier texte contenant une liste de commandes à exécuter **séquentiellement**.
Exemple de fichier `script.txt` :
```
echo "Début du script"
mkdir test
cd test
touch fichier.txt
echo "Contenu" > fichier.txt
ls
cd ..
```

### **📄 Implémentation de `RunCommand`**
```java
package fr.terminal.commands;

import fr.terminal.FileSystem;
import fr.terminal.CommandParser;
import java.util.Arrays;

/**
 * Commande 'run' : exécute un script (fichier contenant des commandes).
 * Usage: run <filename>
 */
public class RunCommand implements Command {
    private FileSystem fileSystem;
    private CommandParser commandParser;

    public RunCommand(FileSystem fileSystem, CommandParser commandParser) {
        this.fileSystem = fileSystem;
        this.commandParser = commandParser;
    }

    @Override
    public String execute(String[] args) {
        if (args.length == 0) {
            return "Usage: run <filename>";
        }

        String fileName = args[0];
        if (!fileSystem.exists(fileName)) {
            return "Fichier introuvable: " + fileName;
        }

        String scriptContent = fileSystem.cat(fileName);
        String[] lines = scriptContent.split("\n");
        StringBuilder output = new StringBuilder();

        // Sauvegarder le répertoire courant pour le restaurer après
        String originalDir = fileSystem.getCurrentDirectory();

        for (String line : lines) {
            line = line.trim();
            if (line.isEmpty() || line.startsWith("#")) {
                continue; // Ignorer les lignes vides et les commentaires
            }
            String result = commandParser.execute(line, fileSystem.getCurrentDirectory());
            if (!result.isEmpty()) {
                output.append(result).append("\n");
            }
        }

        // Restaurer le répertoire original
        fileSystem.setCurrentDirectory(originalDir);

        return output.toString().isEmpty() ?
               "Script exécuté avec succès." :
               output.toString();
    }
}
```

```java
    printPrompt();

// Démarre le mode édition
private void startEditMode(String args) {
    isEditing = true;
    String[] editArgs = args.split(" ");
    String editorType = "nano";
    String fileName;

    if (editArgs[0].equals("--nano") || editArgs[0].equals("--vim")) {
        editorType = editArgs[0].substring(2);
        fileName = editArgs[1];
    } else {
        fileName = editArgs[0];

    currentEditFile = fileName;
    editBuffer.setLength(0);

    if (fileSystem.exists(fileName)) {
        editBuffer.append(fileSystem.cat(fileName));

    } else {

private void handleEditorInput(String input) {

    if (result != null) {
```

```java
package fr.terminal.editors;

import fr.terminal.FileSystem;
import fr.terminal.TerminalEmulator;
import java.util.ArrayList;
import java.util.List;

/**
 * Éditeur nano adapté à Swing.
 */
public class NanoEditorSwing implements TextEditorSwing {
    private TerminalEmulator terminal;
    private FileSystem fileSystem;
    private String fileName;
    private List<String> lines;
    private StringBuilder currentLine;

    public NanoEditorSwing(TerminalEmulator terminal, FileSystem fileSystem, String fileName) {
        this.terminal = terminal;
        this.fileSystem = fileSystem;
        this.fileName = fileName;
        this.lines = new ArrayList<>();
        this.currentLine = new StringBuilder();

        if (fileSystem.exists(fileName)) {
            String content = fileSystem.cat(fileName);
            for (String line : content.split("\n")) {
                lines.add(line);
            }
        }
    }

    @Override
    public void start() {
        terminal.appendToOutput("--- Nano: Édition de '" + fileName + "' ---\n");
        terminal.appendToOutput("Commandes: :wq (sauvegarder et quitter), :q (quitter)\n");
        if (!lines.isEmpty()) {
            terminal.appendToOutput("Contenu actuel:\n");
            for (String line : lines) {
                terminal.appendToOutput(line + "\n");
            }
        }
        terminal.appendToOutput("nano> ");
    }

    @Override
    public String handleInput(String input) {

            lines.add(currentLine.toString());
            return "SAVE:" + String.join("\n", lines);
        } else if (input.equals(":q")) {
            return "CANCEL";

            currentLine.setLength(0);
            currentLine.append(input);
            lines.add(currentLine.toString());
            currentLine = new StringBuilder();
            return null; // Continuer
        }
    }

    @Override
    public String getName() {
        return "nano";
    }
}
```

```java
package fr.terminal.editors;

import fr.terminal.FileSystem;
import fr.terminal.TerminalEmulator;
import java.util.ArrayList;
import java.util.List;

/**
 * Éditeur vim adapté à Swing (simplifié).
 */
public class VimEditorSwing implements TextEditorSwing {
    private TerminalEmulator terminal;
    private FileSystem fileSystem;
    private String fileName;
    private List<String> lines;
    private int currentLineIndex;
    private boolean insertMode = false;

    public VimEditorSwing(TerminalEmulator terminal, FileSystem fileSystem, String fileName) {
        this.terminal = terminal;
        this.fileSystem = fileSystem;
        this.fileName = fileName;
        this.lines = new ArrayList<>();
        this.currentLineIndex = 0;

        if (fileSystem.exists(fileName)) {
            String content = fileSystem.cat(fileName);
            for (String line : content.split("\n")) {
                lines.add(line);
            }
        } else {
            lines.add(""); // Ligne vide par défaut
        }
    }

    @Override
    public void start() {
        terminal.appendToOutput("--- Vim: Édition de '" + fileName + "' ---\n");
        terminal.appendToOutput("Mode: COMMANDE | Tapez 'i' pour passer en mode insertion\n");
        terminal.appendToOutput("Commandes: :wq (sauvegarder), :q! (quitter), :esc (mode commande)\n");
        displayCurrentLine();
    }

    private void displayCurrentLine() {
        terminal.appendToOutput("vim [" + (insertMode ? "INSERT" : "COMMAND") + "] > " + lines.get(currentLineIndex) + "\n");
    }

    @Override
    public String handleInput(String input) {
        if (insertMode) {
            if (input.equals(":esc")) {
                insertMode = false;
                terminal.appendToOutput("Mode: COMMANDE\n");
                displayCurrentLine();
                return null;
            } else {
                // Ajouter à la ligne courante
                lines.set(currentLineIndex, lines.get(currentLineIndex) + input);
                displayCurrentLine();
                return null;
            }
        } else {
            if (input.equals("i")) {
                insertMode = true;
                terminal.appendToOutput("Mode: INSERT\n");
                displayCurrentLine();
                return null;
            } else if (input.equals(":wq")) {
                return "SAVE:" + String.join("\n", lines);
            } else if (input.equals(":q!")) {
                return "CANCEL";
            } else if (input.equals(":esc")) {
                // Déjà en mode commande
                return null;
            } else {
                terminal.appendToOutput("Commande inconnue. Tapez 'i' pour éditer.\n");
                displayCurrentLine();
                return null;
            }
        }
    }

    @Override
    public String getName() {
        return "vim";
    }
}
```

## **📌 1. Architecture des Redirections et Pipes**
### **Concepts Clés**
| Symbole | Nom          | Description                                                                 |
|---------|--------------|-----------------------------------------------------------------------------|
| `>`     | Redirection sortie (écrasement) | `commande > fichier` : Écrit la sortie de `commande` dans `fichier` (écrase). |
| `>>`    | Redirection sortie (ajout)     | `commande >> fichier` : Ajoute la sortie de `commande` à `fichier`.       |
| `<`     | Redirection entrée            | `commande < fichier` : Utilise `fichier` comme entrée pour `commande`.      |
| `|`     | Pipe                          | `commande1 | commande2` : La sortie de `commande1` devient l'entrée de `commande2`.   |

---

### **Exemples**
```bash
# Redirections
echo "Hello" > fichier.txt       # Écrit "Hello" dans fichier.txt
cat fichier.txt >> autre.txt     # Ajoute le contenu de fichier.txt à autre.txt
sort < fichier.txt              # Trie le contenu de fichier.txt

# Pipes
ls | grep "txt"                  # Liste les fichiers et filtre ceux contenant "txt"
cat fichier.txt | wc -l          # Compte le nombre de lignes dans fichier.txt
echo "Hello" | tr "l" "L"        # Remplace "l" par "L" dans "Hello" → "HeLLo"
```

### **📄 Classe `Redirection`**
Stocke les informations sur les redirections d'entrée/sortie.

```java
package fr.terminal;

import java.util.ArrayList;
import java.util.List;

/**
 * Classe pour gérer les redirections d'entrée/sortie.
 */
public class Redirection {
    public enum Type {
        NONE,       // Pas de redirection
        OUTPUT,     // > (écrasement)
        APPEND,     // >> (ajout)
        INPUT       // < (entrée)
    }

    private Type type;
    private String fileName;

    public Redirection(Type type, String fileName) {
        this.type = type;
        this.fileName = fileName;
    }

    public Type getType() {
        return type;
    }

    public String getFileName() {
        return fileName;
    }

    /**
     * Analyse une commande pour extraire les redirections.
     * @param args Arguments de la commande.
     * @return Liste des redirections trouvées.
     */
    public static List<Redirection> parseRedirections(String[] args) {
        List<Redirection> redirections = new ArrayList<>();
        List<String> cleanedArgs = new ArrayList<>();

        for (int i = 0; i < args.length; i++) {
            String arg = args[i];
            if (arg.equals(">") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.OUTPUT, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else if (arg.equals(">>") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.APPEND, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else if (arg.equals("<") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.INPUT, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else {
                cleanedArgs.add(arg);
            }
        }

        // Stocker les arguments nettoyés dans la première redirection (pour compatibilité)
        if (!cleanedArgs.isEmpty() && !redirections.isEmpty()) {
            redirections.get(0).cleanedArgs = cleanedArgs.toArray(new String[0]);
        }

        return redirections;
    }

    // Champ temporaire pour stocker les arguments nettoyés
    public String[] cleanedArgs;
}
```

```java
        for (String part : parts) {
            commandList.add(part.trim().split("\\s+"));
        }
        return new Pipe(commandList);
    }
```

### **📄 Mise à Jour de `CommandParser`**
Modifie `CommandParser` pour gérer les redirections et pipes.

```java
package fr.terminal;

import fr.terminal.commands.*;
import java.util.*;

/**
 * Classe responsable de l'analyse et de l'exécution des commandes,
 * avec support des redirections et pipes.
 */
public class CommandParser {
    private FileSystem fileSystem;
    private Map<String, Command> commands;

    public CommandParser(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
        this.commands = new HashMap<>();
        initializeCommands();
    }

    private void initializeCommands() {
        commands.put("ls", new LsCommand(fileSystem));
        commands.put("cd", new CdCommand(fileSystem));
        commands.put("cat", new CatCommand(fileSystem));
        commands.put("echo", new EchoCommand(fileSystem));
        commands.put("mkdir", new MkdirCommand(fileSystem));
        commands.put("touch", new TouchCommand(fileSystem));
        commands.put("rm", new RmCommand(fileSystem));
        commands.put("pwd", new PwdCommand(fileSystem));
        commands.put("help", new HelpCommand());
        commands.put("clear", new ClearCommand());
        commands.put("edit", new EditCommand(fileSystem));
        commands.put("run", new RunCommand(fileSystem, this));
        // Ajouter des commandes utiles pour les pipes
        commands.put("grep", new GrepCommand(fileSystem));
        commands.put("wc", new WcCommand(fileSystem));
        commands.put("tr", new TrCommand(fileSystem));
        commands.put("sort", new SortCommand(fileSystem));
    }

    /**
     * Exécute une commande avec gestion des redirections et pipes.
     */
    public String execute(String input, String currentDirectory) {
        // Vérifier si la commande contient un pipe
        if (input.contains("|")) {
            return executePipe(input);
        }

        // Sinon, traiter les redirections
        String[] args = input.split("\\s+");
        List<Redirection> redirections = Redirection.parseRedirections(args);

        if (redirections.isEmpty()) {
            // Pas de redirection, exécuter normalement
            return executeCommand(args, currentDirectory);
        } else {
            // Exécuter avec redirections
            return executeWithRedirections(redirections, currentDirectory);
        }
    }

    /**
     * Exécute une commande avec des redirections.
     */
    private String executeWithRedirections(List<Redirection> redirections, String currentDirectory) {
        Redirection redirection = redirections.get(0);
        String[] args = redirection.cleanedArgs;
        String commandName = args[0];
        Command command = commands.get(commandName);

        if (command == null) {
            return "Commande introuvable: " + commandName;
        }

        // Gérer l'entrée redirigée (<)
        String inputContent = null;
        for (Redirection r : redirections) {
            if (r.getType() == Redirection.Type.INPUT) {
                if (fileSystem.exists(r.getFileName())) {
                    inputContent = fileSystem.cat(r.getFileName());
                } else {
                    return "Fichier introuvable pour l'entrée: " + r.getFileName();
                }
            }
        }

        // Exécuter la commande avec l'entrée redirigée
        String output = command.execute(args, inputContent);

        // Gérer la sortie redirigée (>, >>)
        for (Redirection r : redirections) {
            if (r.getType() == Redirection.Type.OUTPUT || r.getType() == Redirection.Type.APPEND) {
                if (r.getType() == Redirection.Type.OUTPUT) {
                    fileSystem.echo(r.getFileName(), output);
                } else {
                    // APPEND: lire le contenu existant et ajouter
                    String existingContent = fileSystem.exists(r.getFileName()) ?
                        fileSystem.cat(r.getFileName()) : "";
                    fileSystem.echo(r.getFileName(), existingContent + output);
                }
                return ""; // Ne pas afficher la sortie si elle est redirigée
            }
        }

        return output;
    }

    /**
     * Exécute une commande sans redirections.
     */
    private String executeCommand(String[] args, String currentDirectory) {
        if (args.length == 0) {
            return "";
        }

        String commandName = args[0];
        Command command = commands.get(commandName);

        if (command == null) {
            return "Commande introuvable: " + commandName;
        }

        return command.execute(args);
    }

    /**
     * Exécute une chaîne de commandes avec pipes.
     */
    private String executePipe(String input) {
        Pipe pipe = Pipe.parsePipe(input);
        List<String[]> commandList = pipe.getCommands();

        if (commandList.isEmpty()) {
            return "";
        }

        // Exécuter la première commande
        String currentOutput = executeCommand(commandList.get(0), fileSystem.getCurrentDirectory());

        // Exécuter les commandes suivantes en passant la sortie précédente comme entrée
        for (int i = 1; i < commandList.size(); i++) {
            String[] args = commandList.get(i);
            String commandName = args[0];
            Command command = commands.get(commandName);

            if (command == null) {
                return "Commande introuvable dans le pipe: " + commandName;
            }

            // Passer la sortie précédente comme entrée
            currentOutput = command.execute(args, currentOutput);
        }

        return currentOutput;
    }
}
```

### **📄 Mise à Jour de `RunCommand`**

```java
package fr.terminal.commands;

import fr.terminal.FileSystem;
import fr.terminal.CommandParser;

/**
 * Commande 'run' : exécute un script (fichier contenant des commandes).
 * Supporte les redirections et pipes.
 */
public class RunCommand implements Command {
    private FileSystem fileSystem;
    private CommandParser commandParser;

    public RunCommand(FileSystem fileSystem, CommandParser commandParser) {
        this.fileSystem = fileSystem;
        this.commandParser = commandParser;
    }

    @Override
    public String execute(String[] args, String stdin) {
        if (args.length == 0) {
            return "Usage: run <filename>";
        }

        String fileName = args[0];
        if (!fileSystem.exists(fileName)) {
            return "Fichier introuvable: " + fileName;
        }

        String scriptContent = fileSystem.cat(fileName);
        String[] lines = scriptContent.split("\n");
        StringBuilder output = new StringBuilder();

        // Sauvegarder le répertoire courant pour le restaurer après
        String originalDir = fileSystem.getCurrentDirectory();

        for (String line : lines) {
            line = line.trim();
            if (line.isEmpty() || line.startsWith("#")) {
                continue; // Ignorer les lignes vides et les commentaires
            }
            String result = commandParser.execute(line, fileSystem.getCurrentDirectory());
            if (!result.isEmpty()) {
                output.append(result).append("\n");
            }
        }

        // Restaurer le répertoire original
        fileSystem.setCurrentDirectory(originalDir);

        return output.toString().isEmpty() ?
               "Script exécuté avec succès." :
               output.toString();
    }
}
```

/**
 * Classe principale pour l'interface graphique de l'émulateur de terminal.
 * Gère l'affichage, la saisie des commandes, et les modes d'édition.
 */
public class TerminalEmulator {
    private JFrame frame;
    private JTextPane outputArea;
    private JTextField inputField;
    private FileSystem fileSystem;
    private CommandParser commandParser;
    private String currentDirectory;
    
    // Pour le mode édition
    private TextEditorSwing currentEditor;
    private String currentEditFile;
    private boolean isEditing = false;

    /**
     * Constructeur : initialise l'interface graphique et le système de fichiers.
     */
    public TerminalEmulator() {
        fileSystem = new FileSystem();
        commandParser = new CommandParser(fileSystem);
        currentDirectory = fileSystem.getRoot();
        initializeUI();
    }

    /**
     * Initialise l'interface utilisateur (UI).
     */
    private void initializeUI() {
        frame = new JFrame("Terminal Emulator");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setSize(800, 600);
        frame.setLayout(new BorderLayout());

        // Zone de sortie (non éditable)
        outputArea = new JTextPane();
        outputArea.setEditable(false);
        outputArea.setBackground(Color.BLACK);
        outputArea.setForeground(Color.GREEN);
        outputArea.setFont(new Font("Monospaced", Font.PLAIN, 14));
        JScrollPane scrollPane = new JScrollPane(outputArea);
        frame.add(scrollPane, BorderLayout.CENTER);

        // Champ de saisie
        inputField = new JTextField();
        inputField.setBackground(Color.BLACK);
        inputField.setForeground(Color.GREEN);
        inputField.setFont(new Font("Monospaced", Font.PLAIN, 14));
        inputField.addActionListener(e -> executeCommand());
        frame.add(inputField, BorderLayout.SOUTH);

        // Gestion des touches (flèches haut/bas pour l'historique)
        inputField.addKeyListener(new KeyAdapter() {
            @Override
            public void keyPressed(KeyEvent e) {
                if (e.getKeyCode() == KeyEvent.VK_UP || e.getKeyCode() == KeyEvent.VK_DOWN) {
                    // TODO: Implémenter l'historique des commandes
                }
            }
        });

        // Afficher le prompt initial
        printPrompt();

        frame.setVisible(true);
    }

    /**
     * Affiche le prompt dans la zone de sortie.
     */
    private void printPrompt() {
        try {
            StyledDocument doc = outputArea.getStyledDocument();
            doc.insertString(doc.getLength(), currentDirectory + " > ", getPromptStyle());
        } catch (BadLocationException ex) {
            ex.printStackTrace();
        }
    }

    /**
     * Retourne le style pour le prompt.
     */
    private Style getPromptStyle() {
        StyleContext sc = StyleContext.getDefaultStyleContext();
        Style style = sc.addStyle("PromptStyle", null);
        StyleConstants.setForeground(style, Color.GREEN);
        StyleConstants.setBold(style, true);
        return style;
    }

    /**
     * Exécute la commande saisie par l'utilisateur.
     */
    private void executeCommand() {
        String command = inputField.getText().trim();
        inputField.setText("");
        
        if (command.isEmpty()) {
            printPrompt();
            return;
        }

        appendToOutput(command + "\n");

        if (isEditing) {
            handleEditorInput(command);
            return;
        }

        if (command.startsWith("edit ")) {
            startEditMode(command.substring(5).trim());
            return;
        }

        String output = commandParser.execute(command, currentDirectory);
        appendToOutput(output + "\n");

        if (command.startsWith("cd ")) {
            currentDirectory = fileSystem.getCurrentDirectory();
        }

        printPrompt();
    }

    /**
     * Démarre le mode édition (nano ou vim).
     */
    private void startEditMode(String args) {
        isEditing = true;
        String[] editArgs = args.split("\\s+");
        String editorType = "nano";
        String fileName;

        if (editArgs.length > 0 && (editArgs[0].equals("--nano") || editArgs[0].equals("--vim"))) {
            editorType = editArgs[0].substring(2);
            if (editArgs.length < 2) {
                appendToOutput("Usage: edit [--nano|--vim] <filename>\n");
                isEditing = false;
                printPrompt();
                return;
            }
            fileName = editArgs[1];
        } else {
            fileName = editArgs[0];
        }

        currentEditFile = fileName;

        if (editorType.equals("nano")) {
            currentEditor = new NanoEditorSwing(this, fileSystem, fileName);
        } else {
            currentEditor = new VimEditorSwing(this, fileSystem, fileName);
        }

        appendToOutput("--- Édition avec " + editorType + " ---\n");
        currentEditor.start();
    }

    /**
     * Gère les entrées en mode édition.
     */
    private void handleEditorInput(String input) {
        String result = currentEditor.handleInput(input);
        if (result != null) {
            if (result.startsWith("SAVE:")) {
                fileSystem.echo(currentEditFile, result.substring(5));
                appendToOutput("Fichier '" + currentEditFile + "' sauvegardé.\n");
            } else if (result.equals("CANCEL")) {
                appendToOutput("Édition annulée.\n");
            }
            endEditMode();
        } else {
            appendToOutput(input + "\n");
        }
    }

    /**
     * Termine le mode édition.
     */
    private void endEditMode() {
        isEditing = false;
        currentEditor = null;
        currentEditFile = null;
        printPrompt();
    }

    /**
     * Ajoute du texte à la zone de sortie.
     */
    public void appendToOutput(String text) {
        try {
            StyledDocument doc = outputArea.getStyledDocument();
            doc.insertString(doc.getLength(), text, null);
            outputArea.setCaretPosition(doc.getLength());
        } catch (BadLocationException ex) {
            ex.printStackTrace();
        }
    }
}

package fr.terminal;

import java.util.*;

/**
 * Classe représentant un système de fichiers simplifié.
 * Gère les fichiers et répertoires sous forme de structure arborescente.
 */
public class FileSystem {
    private static final String ROOT = "/";
    private String currentDirectory;
    private Map<String, Set<String>> directories;
    private Map<String, String> files;

    /**
     * Constructeur : initialise le système de fichiers avec un répertoire racine.
     */
    public FileSystem() {
        currentDirectory = ROOT;
        directories = new HashMap<>();
        files = new HashMap<>();
        directories.put(ROOT, new HashSet<>());
    }

    /**
     * Retourne le répertoire racine.
     */
    public String getRoot() {
        return ROOT;
    }

    /**
     * Retourne le répertoire courant.
     */
    public String getCurrentDirectory() {
        return currentDirectory;
    }

    /**
     * Change le répertoire courant.
     */
    public void setCurrentDirectory(String path) {
        if (directories.containsKey(path)) {
            currentDirectory = path;
        }
    }

    /**
     * Crée un nouveau répertoire.
     */
    public boolean mkdir(String dirName) {
        String fullPath = getFullPath(dirName);
        if (directories.containsKey(fullPath)) {
            return false;
        }
        directories.put(fullPath, new HashSet<>());
        directories.get(currentDirectory).add(dirName);
        return true;
    }

    /**
     * Crée un nouveau fichier.
     */
    public boolean touch(String fileName) {
        String fullPath = getFullPath(fileName);
        if (files.containsKey(fullPath)) {
            return false;
        }
        files.put(fullPath, "");
        return true;
    }

    /**
     * Supprime un fichier ou un répertoire.
     */
    public boolean rm(String name) {
        String fullPath = getFullPath(name);
        if (files.containsKey(fullPath)) {
            files.remove(fullPath);
            return true;
        } else if (directories.containsKey(fullPath)) {
            directories.remove(fullPath);
            directories.get(currentDirectory).remove(name);
            return true;
        }
        return false;
    }

    /**
     * Liste le contenu du répertoire courant.
     */
    public List<String> ls() {
        List<String> contents = new ArrayList<>();
        Set<String> dirContents = directories.getOrDefault(currentDirectory, new HashSet<>());
        for (String item : dirContents) {
            String fullPath = getFullPath(item);
            if (directories.containsKey(fullPath)) {
                contents.add(item + "/");
            } else if (files.containsKey(fullPath)) {
                contents.add(item);
            }
        }
        Collections.sort(contents);
        return contents;
    }

    /**
     * Lit le contenu d'un fichier.
     */
    public String cat(String fileName) {
        String fullPath = getFullPath(fileName);
        return files.getOrDefault(fullPath, "Fichier introuvable: " + fileName);
    }

    /**
     * Écrit dans un fichier.
     */
    public boolean echo(String fileName, String content) {
        String fullPath = getFullPath(fileName);
        files.put(fullPath, content);
        return true;
    }

    /**
     * Retourne le chemin absolu à partir d'un nom de fichier/répertoire.
     */
    private String getFullPath(String name) {
        if (currentDirectory.equals(ROOT)) {
            return ROOT + name;
        }
        return currentDirectory + "/" + name;
    }

    /**
     * Vérifie si un fichier ou répertoire existe.
     */
    public boolean exists(String name) {
        String fullPath = getFullPath(name);
        return files.containsKey(fullPath) || directories.containsKey(fullPath);
    }

    /**
     * Retourne le chemin absolu du répertoire parent.
     */
    public String getParentDirectory(String path) {
        if (path.equals(ROOT)) {
            return ROOT;
        }
        String[] parts = path.split("/");
        if (parts.length == 2) {
            return ROOT;
        }
        StringBuilder parentPath = new StringBuilder();
        for (int i = 1; i < parts.length - 1; i++) {
            parentPath.append("/").append(parts[i]);
        }
        return parentPath.length() == 0 ? ROOT : parentPath.toString();
    }
}

package fr.terminal;

import fr.terminal.commands.*;
import java.util.*;

/**
 * Classe responsable de l'analyse et de l'exécution des commandes.
 * Supporte les redirections (>, >>, <) et les pipes (|).
 */
public class CommandParser {
    private FileSystem fileSystem;
    private Map<String, Command> commands;

    /**
     * Constructeur : initialise les commandes disponibles.
     */
    public CommandParser(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
        this.commands = new HashMap<>();
        initializeCommands();
    }

    /**
     * Initialise les commandes disponibles.
     */
    private void initializeCommands() {
        commands.put("ls", new LsCommand(fileSystem));
        commands.put("cd", new CdCommand(fileSystem));
        commands.put("cat", new CatCommand(fileSystem));
        commands.put("echo", new EchoCommand(fileSystem));
        commands.put("mkdir", new MkdirCommand(fileSystem));
        commands.put("touch", new TouchCommand(fileSystem));
        commands.put("rm", new RmCommand(fileSystem));
        commands.put("pwd", new PwdCommand(fileSystem));
        commands.put("help", new HelpCommand());
        commands.put("clear", new ClearCommand());
        commands.put("edit", new EditCommand(fileSystem, this));
        commands.put("run", new RunCommand(fileSystem, this));
        commands.put("grep", new GrepCommand(fileSystem));
        commands.put("wc", new WcCommand(fileSystem));
        commands.put("tr", new TrCommand(fileSystem));
        commands.put("sort", new SortCommand(fileSystem));
    }

    /**
     * Exécute une commande avec gestion des redirections et pipes.
     * @param input Commande complète (ex: "ls | grep txt").
     * @param currentDirectory Répertoire courant.
     * @return Résultat de l'exécution.
     */
    public String execute(String input, String currentDirectory) {
        input = input.trim();
        if (input.isEmpty()) {
            return "";
        }

        // Vérifier si la commande contient un pipe
        if (input.contains("|")) {
            return executePipe(input);
        }

        // Sinon, traiter les redirections
        String[] args = input.split("\\s+");
        List<Redirection> redirections = Redirection.parseRedirections(args);

        if (redirections.isEmpty()) {
            return executeCommand(args, currentDirectory, null);
        } else {
            return executeWithRedirections(redirections, currentDirectory);
        }
    }

    /**
     * Exécute une commande avec des redirections.
     */
    private String executeWithRedirections(List<Redirection> redirections, String currentDirectory) {
        Redirection firstRedirection = redirections.get(0);
        String[] args = firstRedirection.cleanedArgs;
        
        if (args.length == 0) {
            return "Commande invalide.";
        }

        String commandName = args[0];
        Command command = commands.get(commandName);
        if (command == null) {
            return "Commande introuvable: " + commandName;
        }

        // Gérer l'entrée redirigée (<)
        String stdin = null;
        for (Redirection r : redirections) {
            if (r.getType() == Redirection.Type.INPUT) {
                if (fileSystem.exists(r.getFileName())) {
                    stdin = fileSystem.cat(r.getFileName());
                } else {
                    return "Fichier introuvable pour l'entrée: " + r.getFileName();
                }
            }
        }

        // Exécuter la commande avec stdin
        String output = command.execute(args, stdin);

        // Gérer la sortie redirigée (>, >>)
        for (Redirection r : redirections) {
            if (r.getType() == Redirection.Type.OUTPUT || r.getType() == Redirection.Type.APPEND) {
                if (r.getType() == Redirection.Type.OUTPUT) {
                    fileSystem.echo(r.getFileName(), output);
                } else {
                    // APPEND: lire le contenu existant et ajouter
                    String existingContent = fileSystem.exists(r.getFileName()) ?
                        fileSystem.cat(r.getFileName()) : "";
                    fileSystem.echo(r.getFileName(), existingContent + output);
                }
                return ""; // Ne pas afficher la sortie si elle est redirigée
            }
        }

        return output;
    }

    /**
     * Exécute une commande sans redirections.
     */
    private String executeCommand(String[] args, String currentDirectory, String stdin) {
        if (args.length == 0) {
            return "";
        }

        String commandName = args[0];
        Command command = commands.get(commandName);
        if (command == null) {
            return "Commande introuvable: " + commandName;
        }

        return command.execute(args, stdin);
    }

    /**
     * Exécute une chaîne de commandes avec pipes.
     */
    private String executePipe(String input) {
        Pipe pipe = Pipe.parsePipe(input);
        List<String[]> commandList = pipe.getCommands();

        if (commandList.isEmpty()) {
            return "";
        }

        // Exécuter la première commande
        String currentOutput = executeCommand(commandList.get(0), fileSystem.getCurrentDirectory(), null);

        // Exécuter les commandes suivantes en passant la sortie précédente comme stdin
        for (int i = 1; i < commandList.size(); i++) {
            String[] args = commandList.get(i);
            String commandName = args[0];
            Command command = commands.get(commandName);
            if (command == null) {
                return "Commande introuvable dans le pipe: " + commandName;
            }
            currentOutput = command.execute(args, currentOutput);
        }

        return currentOutput;
    }
}

// DESCRIPTION: Gestion des redirections d'entrée/sortie.

package fr.terminal;

import java.util.ArrayList;
import java.util.List;

/**
 * Classe pour gérer les redirections d'entrée/sortie (>, >>, <).
 */
public class Redirection {
    /**
     * Type de redirection.
     */
    public enum Type {
        NONE,       // Pas de redirection
        OUTPUT,     // > (écrasement)
        APPEND,     // >> (ajout)
        INPUT       // < (entrée)
    }

    private Type type;
    private String fileName;
    public String[] cleanedArgs; // Arguments nettoyés (sans les redirections)

    /**
     * Constructeur.
     * @param type Type de redirection.
     * @param fileName Nom du fichier.
     */
    public Redirection(Type type, String fileName) {
        this.type = type;
        this.fileName = fileName;
    }

    /**
     * Retourne le type de redirection.
     */
    public Type getType() {
        return type;
    }

    /**
     * Retourne le nom du fichier.
     */
    public String getFileName() {
        return fileName;
    }

    /**
     * Analyse une commande pour extraire les redirections.
     * @param args Arguments de la commande.
     * @return Liste des redirections trouvées.
     */
    public static List<Redirection> parseRedirections(String[] args) {
        List<Redirection> redirections = new ArrayList<>();
        List<String> cleanedArgs = new ArrayList<>();

        for (int i = 0; i < args.length; i++) {
            String arg = args[i];
            if (arg.equals(">") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.OUTPUT, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else if (arg.equals(">>") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.APPEND, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else if (arg.equals("<") && i + 1 < args.length) {
                redirections.add(new Redirection(Type.INPUT, args[i + 1]));
                i++; // Sauter le nom du fichier
            } else {
                cleanedArgs.add(arg);
            }
        }

        // Stocker les arguments nettoyés dans la première redirection
        if (!cleanedArgs.isEmpty() && !redirections.isEmpty()) {
            redirections.get(0).cleanedArgs = cleanedArgs.toArray(new String[0]);
        }

        return redirections;
    }
}

package fr.terminal;

import java.util.ArrayList;
import java.util.List;

/**
 * Classe pour gérer les pipes entre commandes.
 */
public class Pipe {
    private List<String[]> commands;

    /**
     * Constructeur.
     * @param commands Liste des commandes séparées par des pipes.
     */
    public Pipe(List<String[]> commands) {
        this.commands = commands;
    }

    /**
     * Retourne la liste des commandes.
     */
    public List<String[]> getCommands() {
        return commands;
    }

    /**
     * Analyse une chaîne de commandes avec pipes.
     * @param input Chaîne complète (ex: "ls | grep txt").
     * @return Objet Pipe contenant les commandes séparées.
     */
    public static Pipe parsePipe(String input) {
        String[] parts = input.split("\\|");
        List<String[]> commandList = new ArrayList<>();
        for (String part : parts) {
            String trimmedPart = part.trim();
            if (!trimmedPart.isEmpty()) {
                commandList.add(trimmedPart.split("\\s+"));
            }
        }
        return new Pipe(commandList);
    }
}

package fr.terminal.commands;

import fr.terminal.FileSystem;

/**
 * Commande 'cd' : change le répertoire courant.
 */
public class CdCommand implements Command {
    private FileSystem fileSystem;

    public CdCommand(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
    }

    @Override
    public String execute(String[] args, String stdin) {
        if (args.length == 0) {
            return "Usage: cd <directory>";
        }

        String targetDir = args[0];
        if (targetDir.equals("..")) {
            String parentDir = fileSystem.getParentDirectory(fileSystem.getCurrentDirectory());
            fileSystem.setCurrentDirectory(parentDir);
            return "";
        } else if (targetDir.equals("/")) {
            fileSystem.setCurrentDirectory(fileSystem.getRoot());
            return "";
        } else {
            String currentDir = fileSystem.getCurrentDirectory();
            String fullPath = currentDir.equals("/") ? "/" + targetDir : currentDir + "/" + targetDir;
            if (fileSystem.exists(targetDir)) {
                fileSystem.setCurrentDirectory(fullPath);
                return "";
            }
            return "Répertoire introuvable: " + targetDir;
        }
    }
}

// ============================================
package fr.terminal.commands;

import fr.terminal.FileSystem;
import fr.terminal.CommandParser;

/**
 * Commande 'run' : exécute un script (fichier contenant des commandes).
 * Supporte les redirections et pipes.
 */
public class RunCommand implements Command {
    private FileSystem fileSystem;
    private CommandParser commandParser;

    public RunCommand(FileSystem fileSystem, CommandParser commandParser) {
        this.fileSystem = fileSystem;
        this.commandParser = commandParser;
    }

    @Override
    public String execute(String[] args, String stdin) {
        if (args.length == 0) {
            return "Usage: run <filename>";
        }

        String fileName = args[0];
        if (!fileSystem.exists(fileName)) {
            return "Fichier introuvable: " + fileName;
        }

        String scriptContent = fileSystem.cat(fileName);
        String[] lines = scriptContent.split("\n");
        StringBuilder output = new StringBuilder();

        // Sauvegarder le répertoire courant pour le restaurer après
        String originalDir = fileSystem.getCurrentDirectory();

        for (String line : lines) {
            line = line.trim();
            if (line.isEmpty() || line.startsWith("#")) {
                continue; // Ignorer les lignes vides et les commentaires
            }
            String result = commandParser.execute(line, fileSystem.getCurrentDirectory());
            if (!result.isEmpty() && !result.startsWith("MODE_EDIT:")) {
                output.append(result).append("\n");
            }
        }

        // Restaurer le répertoire original
        fileSystem.setCurrentDirectory(originalDir);

        return output.toString().isEmpty() ?
               "Script exécuté avec succès." :
               output.toString();
    }
}

/**
 * Commande 'grep' : filtre les lignes contenant un motif.
 * Usage: grep <motif> [fichier] ou grep <motif> < stdin
 */
public class GrepCommand implements Command {
    private FileSystem fileSystem;

    public GrepCommand(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
    }

    @Override
    public String execute(String[] args, String stdin) {
        if (args.length == 0) {
            return "Usage: grep <pattern> [file]";
        }

        String pattern = args[0];
        String content;

        if (args.length > 1) {
            // Lire depuis un fichier
            String fileName = args[1];
            if (!fileSystem.exists(fileName)) {
                return "Fichier introuvable: " + fileName;
            }
            content = fileSystem.cat(fileName);
        } else if (stdin != null) {
            // Lire depuis stdin
            content = stdin;
        } else {
            return "Usage: grep <pattern> [file] ou utiliser un pipe";
        }

        // Filtrer les lignes
        StringBuilder output = new StringBuilder();
        for (String line : content.split("\n")) {
            if (line.contains(pattern)) {
                output.append(line).append("\n");
            }
        }

        return output.toString();
    }
}

/**
 * Commande 'tr' : remplace ou supprime des caractères.
 * Usage: tr <set1> <set2> [fichier] ou tr <set1> <set2> < stdin
 */
public class TrCommand implements Command {
    private FileSystem fileSystem;

    public TrCommand(FileSystem fileSystem) {
        this.fileSystem = fileSystem;
    }

    @Override
    public String execute(String[] args, String stdin) {
        if (args.length < 2) {
            return "Usage: tr <set1> <set2> [file]";
        }

        String set1 = args[0];
        String set2 = args[1];
        String content;

        if (args.length > 2) {
            // Lire depuis un fichier
            String fileName = args[2];
            if (!fileSystem.exists(fileName)) {
                return "Fichier introuvable: " + fileName;
            }
            content = fileSystem.cat(fileName);
        } else if (stdin != null) {
            // Lire depuis stdin
            content = stdin;
        } else {
            return "Usage: tr <set1> <set2> [file] ou utiliser un pipe";
        }

        // Remplacer les caractères
        StringBuilder output = new StringBuilder();
        for (char c : content.toCharArray()) {
            int index = set1.indexOf(c);
            if (index != -1 && index < set2.length()) {
                output.append(set2.charAt(index));
            } else {
                output.append(c);
            }
        }

        return output.toString();
    }
}

/**

 */

    private TerminalEmulator terminal;
    private FileSystem fileSystem;
    private String fileName;
    private List<String> lines;

    /**
     * Constructeur.
     * @param terminal TerminalEmulator pour afficher les messages.
     * @param fileSystem Système de fichiers.
     * @param fileName Nom du fichier à éditer.

    public NanoEditorSwing(TerminalEmulator terminal, FileSystem fileSystem, String fileName) {

        this.fileSystem = fileSystem;
        this.fileName = fileName;
        this.lines = new ArrayList<>();

        if (fileSystem.exists(fileName)) {
            String content = fileSystem.cat(fileName);
            for (String line : content.split("\n")) {

            }

            return "CANCEL";
        } else {
            lines.add(input);
            return null; // Continuer
        }
    }

package fr.terminal.editors;

import fr.terminal.FileSystem;
import fr.terminal.TerminalEmulator;
import java.util.ArrayList;
import java.util.List;

/**
 * Éditeur vim adapté à Swing (simplifié).
 * Supporte le mode commande et le mode insertion.
 */
public class VimEditorSwing implements TextEditorSwing {
    private TerminalEmulator terminal;
    private FileSystem fileSystem;
    private String fileName;
    private List<String> lines;
    private int currentLineIndex;
    private boolean insertMode = false;

    /**
     * Constructeur.
     * @param terminal TerminalEmulator pour afficher les messages.
     * @param fileSystem Système de fichiers.
     * @param fileName Nom du fichier à éditer.
     */
    public VimEditorSwing(TerminalEmulator terminal, FileSystem fileSystem, String fileName) {
        this.terminal = terminal;
        this.fileSystem = fileSystem;
        this.fileName = fileName;
        this.lines = new ArrayList<>();
        this.currentLineIndex = 0;

        if (fileSystem.exists(fileName)) {
            String content = fileSystem.cat(fileName);
            for (String line : content.split("\n")) {
                lines.add(line);
            }
        } else {
            lines.add(""); // Ligne vide par défaut
        }
    }

    @Override
    public void start() {
        terminal.appendToOutput("--- Vim: Édition de '" + fileName + "' ---\n");
        terminal.appendToOutput("Mode: COMMANDE | Tapez 'i' pour passer en mode insertion\n");
        terminal.appendToOutput("Commandes: :wq (sauvegarder), :q! (quitter), :esc (mode commande)\n");
        displayCurrentLine();
    }

    /**
     * Affiche la ligne courante.
     */
    private void displayCurrentLine() {
        terminal.appendToOutput("vim [" + (insertMode ? "INSERT" : "COMMAND") + "] > " + lines.get(currentLineIndex) + "\n");
    }

    @Override
    public String handleInput(String input) {
        if (insertMode) {
            if (input.equals(":esc")) {
                insertMode = false;
                terminal.appendToOutput("Mode: COMMANDE\n");
                displayCurrentLine();
                return null;
            } else {
                // Ajouter à la ligne courante
                lines.set(currentLineIndex, lines.get(currentLineIndex) + input);
                displayCurrentLine();
                return null;
            }
        } else {
            if (input.equals("i")) {
                insertMode = true;
                terminal.appendToOutput("Mode: INSERT\n");
                displayCurrentLine();
                return null;
            } else if (input.equals(":wq")) {
                return "SAVE:" + String.join("\n", lines);
            } else if (input.equals(":q!")) {
                return "CANCEL";
            } else if (input.equals(":esc")) {
                // Déjà en mode commande
                displayCurrentLine();
                return null;
            } else {
                terminal.appendToOutput("Commande inconnue. Tapez 'i' pour éditer.\n");
                displayCurrentLine();
                return null;
            }
        }
    }

    @Override
    public String getName() {
        return "vim";
    }
}

package fr.terminal;

import org.junit.jupiter.api.*;
import static org.junit.jupiter.api.Assertions.*;

/**
 * Tests d'intégration pour l'émulateur de terminal.
 * Vérifie le bon fonctionnement global avec redirections, pipes et scripts.
 */
class TerminalEmulatorIntegrationTest {
    private FileSystem fileSystem;
    private CommandParser commandParser;

    @BeforeEach
    void setUp() {
        fileSystem = new FileSystem();
        commandParser = new CommandParser(fileSystem);
    }

    @Test
    void testFullWorkflow() {
        // 1. Créer un répertoire et un fichier
        commandParser.execute("mkdir test", "/");
        commandParser.execute("cd test", "/");
        commandParser.execute("touch file.txt", "/test");
        commandParser.execute("echo Hello > file.txt", "/test");

        // 2. Vérifier le contenu
        String catOutput = commandParser.execute("cat file.txt", "/test");
        assertEquals("Hello", catOutput);

        // 3. Utiliser un pipe
        String pipeOutput = commandParser.execute("cat file.txt | grep Hello", "/test");
        assertEquals("Hello", pipeOutput.trim());

        // 4. Utiliser une redirection
        commandParser.execute("echo World >> file.txt", "/test");
        catOutput = commandParser.execute("cat file.txt", "/test");
        assertEquals("Hello\nWorld", catOutput);

        // 5. Retourner à la racine et nettoyer
        commandParser.execute("cd ..", "/test");
        commandParser.execute("rm test", "/");
        assertFalse(fileSystem.exists("test"));
    }

    @Test
    void testScriptExecution() {
        // Créer un script
        fileSystem.echo("script.txt", "echo Line1\necho Line2\necho Line3 | grep Line2");

        // Exécuter le script
        String output = commandParser.execute("run script.txt", "/");
        assertTrue(output.contains("Line1"));
        assertTrue(output.contains("Line2"));
        assertTrue(output.contains("Line2")); // Résultat du grep
    }

    @Test
    void testComplexPipe() {
        fileSystem.echo("data.txt", "apple\nbanana\napple\ncherry");
        String output = commandParser.execute("cat data.txt | grep apple | wc", "/");
        assertEquals("2 2 10", output.trim());
    }

    @Test
    void testRedirectionAndPipe() {
        fileSystem.echo("input.txt", "Hello\nWorld");
        String output = commandParser.execute("cat < input.txt | tr H h", "/");
        assertEquals("hello\nWorld", output);
    }

    @Test
    void testErrorHandling() {
        // Commande inconnue
        String output = commandParser.execute("unknown", "/");
        assertTrue(output.contains("Commande introuvable"));

        // cd vers un répertoire inexistant
        output = commandParser.execute("cd nonexistent", "/");
        assertTrue(output.contains("Répertoire introuvable"));

        // cat sur un fichier inexistant
        output = commandParser.execute("cat nonexistent.txt", "/");
        assertTrue(output.contains("Fichier introuvable"));

        // Redirection avec fichier inexistant

        assertTrue(output.contains("Fichier introuvable pour l'entrée"));
    }

### **2. Édition de Texte**
| Commande | Description | Exemple |
|----------|-------------|---------|
| `edit fichier.txt` | Édite avec `nano` (par défaut) | `edit fichier.txt` |
| `edit --nano fichier.txt` | Force l'éditeur `nano` | `edit --nano fichier.txt` |
| `edit --vim fichier.txt` | Force l'éditeur `vim` | `edit --vim fichier.txt` |

**Modes d'édition :**
- **Nano** :
  - Saisie ligne par ligne.
  - `:wq` pour sauvegarder et quitter.
  - `:q` pour annuler.
- **Vim** :
  - Mode **commande** (par défaut) et mode **insertion** (`i`).
  - `:wq` pour sauvegarder et quitter.
  - `:q!` pour annuler.
  - `:esc` pour revenir en mode commande.

### **3. Redirections**
| Symbole | Description | Exemple |
|---------|-------------|---------|
| `>` | Redirige la sortie (écrasement) | `echo "Hello" > fichier.txt` |
| `>>` | Redirige la sortie (ajout) | `echo "World" >> fichier.txt` |
| `<` | Redirige l'entrée | `cat < fichier.txt` |

**Exemple :**
```bash
echo "Bonjour" > salut.txt
echo "Au revoir" >> salut.txt
cat < salut.txt
```

### **4. Pipes**
| Symbole | Description | Exemple |
|---------|-------------|---------|
| `|` | Passe la sortie de la commande de gauche en entrée de celle de droite | `ls | grep "txt"` |

**Exemple :**
```bash
cat fichier.txt | grep "motif" | wc
cat fichier.txt | tr "a" "A" | sort
```

```java
 *   <li>Création et suppression de fichiers et répertoires.</li>
 *   <li>Navigation entre répertoires (cd, pwd).</li>
 *   <li>Lecture et écriture de fichiers (cat, echo).</li>
 *   <li>Vérification de l'existence de fichiers/répertoires.</li>
 *   <li>Gestion des chemins absolus et relatifs.</li>
 * </ul>
 * </p>
 *
 * <p>
 * <b>Exemple d'utilisation :</b>
 * <pre>
 * FileSystem fs = new FileSystem();
 * fs.mkdir("test");          // Crée un répertoire "test"
 * fs.touch("file.txt");      // Crée un fichier "file.txt"
 * fs.echo("file.txt", "Hello"); // Écrit "Hello" dans "file.txt"
 * String content = fs.cat("file.txt"); // Lit le contenu
 * </pre>
 * </p>
 */
public class FileSystem {
    // Répertoire racine (constante)
    private static final String ROOT = "/";

    // Répertoire courant
    private String currentDirectory;

    // Structure des répertoires : clé = chemin absolu, valeur = ensemble des noms de fichiers/répertoires
    private Map<String, Set<String>> directories;

    // Structure des fichiers : clé = chemin absolu, valeur = contenu du fichier
    private Map<String, String> files;

    /**
     * Constructeur : initialise le système de fichiers avec un répertoire racine.
     * Le répertoire racine est créé automatiquement.
     */
    public FileSystem() {
        this.currentDirectory = ROOT;
        this.directories = new HashMap<>();
        this.files = new HashMap<>();

        // Initialiser le répertoire racine
        this.directories.put(ROOT, new HashSet<>());
    }

    // ============================================
    // Méthodes de base pour le système de fichiers
    // ============================================

    /**
     * Retourne le chemin du répertoire racine.
     * @return Chemin absolu du répertoire racine ("/").
     */
    public String getRoot() {
        return ROOT;
    }

    /**
     * Retourne le répertoire courant.
     * @return Chemin absolu du répertoire courant.
     */
    public String getCurrentDirectory() {
        return this.currentDirectory;
    }

    /**
     * Change le répertoire courant.
     * @param path Chemin absolu du nouveau répertoire courant.
     * @throws IllegalArgumentException Si le répertoire n'existe pas.
     */
    public void setCurrentDirectory(String path) {
        if (!this.directories.containsKey(path)) {
            throw new IllegalArgumentException("Répertoire introuvable: " + path);
        }
        this.currentDirectory = path;
    }

    // ============================================
    // Méthodes pour les répertoires
    // ============================================

    /**
     * Crée un nouveau répertoire dans le répertoire courant.
     * @param dirName Nom du répertoire à créer.
     * @return true si le répertoire a été créé, false s'il existe déjà.
     * @throws IllegalArgumentException Si dirName est vide ou null.
     */
    public boolean mkdir(String dirName) {
        if (dirName == null || dirName.trim().isEmpty()) {
            throw new IllegalArgumentException("Nom de répertoire invalide.");
        }

        String fullPath = getFullPath(dirName);

        // Vérifier si le répertoire existe déjà
        if (this.directories.containsKey(fullPath)) {
            return false;
        }

        // Créer le répertoire
        this.directories.put(fullPath, new HashSet<>());

        // Ajouter le répertoire au répertoire parent
        this.directories.get(this.currentDirectory).add(dirName);

        return true;
    }

    /**
     * Supprime un répertoire ou un fichier.
     * @param name Nom du répertoire ou fichier à supprimer.
     * @return true si la suppression a réussi, false sinon.
     */
    public boolean rm(String name) {
        if (name == null || name.trim().isEmpty()) {
            return false;
        }

        String fullPath = getFullPath(name);

        // Supprimer un fichier
        if (this.files.containsKey(fullPath)) {
            this.files.remove(fullPath);
            this.directories.get(this.currentDirectory).remove(name);
            return true;
        }
        // Supprimer un répertoire (doit être vide)
        else if (this.directories.containsKey(fullPath)) {
            Set<String> contents = this.directories.get(fullPath);
            if (contents.isEmpty()) {
                this.directories.remove(fullPath);
                this.directories.get(this.currentDirectory).remove(name);
                return true;
            } else {
                return false; // Répertoire non vide
            }
        }

        return false;
    }

    /**
     * Supprime un répertoire et tout son contenu (récursif).
     * @param name Nom du répertoire à supprimer.
     * @return true si la suppression a réussi, false sinon.
     */
    public boolean rmdir(String name) {
        if (name == null || name.trim().isEmpty()) {
            return false;
        }

        String fullPath = getFullPath(name);

        if (!this.directories.containsKey(fullPath)) {
            return false;
        }

        // Supprimer récursivement le contenu
        Set<String> contents = new HashSet<>(this.directories.get(fullPath));
        for (String item : contents) {
            String itemPath = fullPath.equals(ROOT) ? ROOT + item : fullPath + "/" + item;
            if (this.directories.containsKey(itemPath)) {
                rmdir(item); // Supprimer récursivement
            } else if (this.files.containsKey(itemPath)) {
                this.files.remove(itemPath);
            }
        }

        // Supprimer le répertoire lui-même
        this.directories.remove(fullPath);
        this.directories.get(this.currentDirectory).remove(name);

        return true;
    }

    /**
     * Liste le contenu du répertoire courant.
     * @return Liste des noms de fichiers et répertoires (les répertoires se terminent par "/").
     */
    public List<String> ls() {
        List<String> contents = new ArrayList<>();
        Set<String> dirContents = this.directories.getOrDefault(this.currentDirectory, new HashSet<>());

        for (String item : dirContents) {
            String fullPath = getFullPath(item);
            if (this.directories.containsKey(fullPath)) {
                contents.add(item + "/"); // Ajouter "/" pour les répertoires
            } else if (this.files.containsKey(fullPath)) {
                contents.add(item);
            }
        }

        Collections.sort(contents); // Trier par ordre alphabétique
        return contents;
    }

    /**
     * Liste le contenu d'un répertoire spécifique.
     * @param dirPath Chemin du répertoire à lister.
     * @return Liste des noms de fichiers et répertoires.
     * @throws IllegalArgumentException Si le répertoire n'existe pas.
     */
    public List<String> ls(String dirPath) {
        if (!this.directories.containsKey(dirPath)) {
            throw new IllegalArgumentException("Répertoire introuvable: " + dirPath);
        }

        List<String> contents = new ArrayList<>();
        Set<String> dirContents = this.directories.get(dirPath);

        for (String item : dirContents) {
            String fullPath = dirPath.equals(ROOT) ? ROOT + item : dirPath + "/" + item;
            if (this.directories.containsKey(fullPath)) {
                contents.add(item + "/");
            } else if (this.files.containsKey(fullPath)) {
                contents.add(item);
            }
        }

        Collections.sort(contents);
        return contents;
    }

    // ============================================
    // Méthodes pour les fichiers
    // ============================================

    /**
     * Crée un nouveau fichier vide.
     * @param fileName Nom du fichier à créer.
     * @return true si le fichier a été créé, false s'il existe déjà.
     * @throws IllegalArgumentException Si fileName est vide ou null.
     */
    public boolean touch(String fileName) {
        if (fileName == null || fileName.trim().isEmpty()) {
            throw new IllegalArgumentException("Nom de fichier invalide.");
        }

        String fullPath = getFullPath(fileName);

        if (this.files.containsKey(fullPath)) {
            return false; // Fichier déjà existant
        }

        this.files.put(fullPath, "");
        return true;
    }

    /**
     * Lit le contenu d'un fichier.
     * @param fileName Nom du fichier à lire.
     * @return Contenu du fichier, ou un message d'erreur si le fichier n'existe pas.
     */
    public String cat(String fileName) {
        String fullPath = getFullPath(fileName);
        return this.files.getOrDefault(fullPath, "Fichier introuvable: " + fileName);
    }

    /**
     * Écrit du contenu dans un fichier (écrasement).
     * @param fileName Nom du fichier.
     * @param content Contenu à écrire.
     * @return true si l'écriture a réussi, false sinon.
     */
    public boolean echo(String fileName, String content) {
        if (fileName == null || fileName.trim().isEmpty()) {
            return false;
        }

        String fullPath = getFullPath(fileName);
        this.files.put(fullPath, content);
        return true;
    }

    /**
     * Ajoute du contenu à la fin d'un fichier.
     * @param fileName Nom du fichier.
     * @param content Contenu à ajouter.
     * @return true si l'ajout a réussi, false sinon.
     */
    public boolean append(String fileName, String content) {
        if (fileName == null || fileName.trim().isEmpty()) {
            return false;
        }

        String fullPath = getFullPath(fileName);
        String existingContent = this.files.getOrDefault(fullPath, "");
        this.files.put(fullPath, existingContent + content);
        return true;
    }

    // ============================================
    // Méthodes utilitaires pour les chemins
    // ============================================

    /**
     * Construit le chemin absolu à partir d'un nom de fichier/répertoire.
     * @param name Nom du fichier ou répertoire.
     * @return Chemin absolu.
     */
    private String getFullPath(String name) {
        if (this.currentDirectory.equals(ROOT)) {
            return ROOT + name;
        }
        return this.currentDirectory + "/" + name;
    }

    /**
     * Vérifie si un fichier ou répertoire existe.
     * @param name Nom du fichier ou répertoire.
     * @return true s'il existe, false sinon.
     */
    public boolean exists(String name) {
        String fullPath = getFullPath(name);
        return this.files.containsKey(fullPath) || this.directories.containsKey(fullPath);
    }

    /**
     * Retourne le chemin absolu du répertoire parent.
     * @param path Chemin dont on veut le parent.
     * @return Chemin absolu du répertoire parent.
     */
    public String getParentDirectory(String path) {
        if (path.equals(ROOT)) {
            return ROOT;
        }

        String[] parts = path.split("/");
        if (parts.length <= 2) {
            return ROOT;
        }

        StringBuilder parentPath = new StringBuilder();
        for (int i = 1; i < parts.length - 1; i++) {
            parentPath.append("/").append(parts[i]);
        }

        return parentPath.length() == 0 ? ROOT : parentPath.toString();
    }

    /**
     * Résout un chemin (relatif ou absolu) en chemin absolu.
     * @param path Chemin à résoudre (peut être relatif ou absolu).
     * @return Chemin absolu résolu.
     * @throws IllegalArgumentException Si le chemin est invalide.
     */
    public String resolvePath(String path) {
        if (path == null || path.trim().isEmpty()) {
            return this.currentDirectory;
        }

        path = path.trim();

        // Si le chemin est absolu (commence par "/")
        if (path.startsWith(ROOT)) {
            return normalizePath(path);
        }

        // Sinon, c'est un chemin relatif : le résoudre par rapport au répertoire courant
        String resolvedPath = this.currentDirectory + "/" + path;
        return normalizePath(resolvedPath);
    }

    /**
     * Normalise un chemin (supprime les "/./" et résout les "/../").
     * @param path Chemin à normaliser.
     * @return Chemin normalisé.
     */
    private String normalizePath(String path) {
        if (path.equals(ROOT)) {
            return ROOT;
        }

        String[] parts = path.split("/");
        List<String> normalizedParts = new ArrayList<>();

        for (String part : parts) {
            if (part.isEmpty() || part.equals(".")) {
                continue; // Ignorer les parties vides ou "."
            } else if (part.equals("..")) {
                if (!normalizedParts.isEmpty()) {
                    normalizedParts.remove(normalizedParts.size() - 1); // Remonter d'un niveau
                }
            } else {
                normalizedParts.add(part);
            }
        }

        if (normalizedParts.isEmpty()) {
            return ROOT;
        }

        StringBuilder normalizedPath = new StringBuilder();
        for (String part : normalizedParts) {
            normalizedPath.append("/").append(part);
        }

        return normalizedPath.toString();
    }

    // ============================================
    // Méthodes pour la gestion des permissions (optionnel)
    // ============================================

    /**
     * Vérifie si un chemin est un répertoire.
     * @param path Chemin à vérifier.
     * @return true si c'est un répertoire, false sinon.
     */
    public boolean isDirectory(String path) {
        return this.directories.containsKey(path);
    }

    /**
     * Vérifie si un chemin est un fichier.
     * @param path Chemin à vérifier.
     * @return true si c'est un fichier, false sinon.
     */
    public boolean isFile(String path) {
        return this.files.containsKey(path);
    }

    // ============================================
    // Méthodes pour la sérialisation (optionnel)
    // ============================================

    /**
     * Exporte l'état du système de fichiers sous forme de chaîne de caractères.
     * Utile pour sauvegarder/restaurer l'état.
     * @return Représentation textuelle du système de fichiers.
     */
    public String exportState() {
        StringBuilder sb = new StringBuilder();
        sb.append("=== Directories ===\\n");
        for (Map.Entry<String, Set<String>> entry : this.directories.entrySet()) {
            sb.append(entry.getKey()).append(": ").append(entry.getValue()).append("\\n");
        }
        sb.append("\\n=== Files ===\\n");
        for (Map.Entry<String, String> entry : this.files.entrySet()) {
            sb.append(entry.getKey()).append(": \"").append(entry.getValue()).append("\"\\n");
        }
        return sb.toString();
    }

    /**
     * Importe l'état du système de fichiers à partir d'une chaîne de caractères.
     * @param state Représentation textuelle du système de fichiers.
     */
    public void importState(String state) {
        // TODO: Implémenter la désérialisation
        throw new UnsupportedOperationException("Non implémenté.");
    }
}
```

## **📝 Exemples d'Utilisation**

### **1. Navigation dans les Répertoires**
```java
FileSystem fs = new FileSystem();
fs.mkdir("documents");       // Crée /documents
fs.mkdir("images");          // Crée /images
fs.setCurrentDirectory("/documents"); // Change de répertoire
System.out.println(fs.getCurrentDirectory()); // Affiche "/documents"
```

### **2. Création et Lecture de Fichiers**
```java
fs.touch("notes.txt");       // Crée /documents/notes.txt
fs.echo("notes.txt", "Bonjour le monde!"); // Écrit dans le fichier
String content = fs.cat("notes.txt"); // Lit le contenu
System.out.println(content); // Affiche "Bonjour le monde!"
```

### **3. Gestion des Chemins**
```java
fs.mkdir("test");
fs.setCurrentDirectory("/test");
fs.mkdir("subdir");          // Crée /test/subdir
System.out.println(fs.resolvePath("../images")); // Affiche "/images"
System.out.println(fs.getParentDirectory("/test/subdir")); // Affiche "/test"
```

### **4. Suppression Récursive**
```java
fs.mkdir("dir1");
fs.setCurrentDirectory("/dir1");
fs.mkdir("dir2");
fs.touch("file.txt");
fs.setCurrentDirectory("/");
fs.rmdir("dir1"); // Supprime /dir1 et tout son contenu
```

### **5. Normalisation des Chemins**
```java
System.out.println(fs.normalizePath("/a/./b/../c")); // Affiche "/a/c"
System.out.println(fs.normalizePath("/a/b/../../c")); // Affiche "/c"
```

## **🎯 Optimisations et Bonnes Pratiques**

1. **Gestion des Chemins** :
   - `resolvePath()` et `normalizePath()` permettent de gérer les chemins **relatifs** et **absolus** de manière robuste.
   - Exemple : `/a/./b/../c` → `/a/c`.

2. **Séparation des Responsabilités** :
   - Les fichiers et répertoires sont stockés dans des **`Map` séparées** pour une gestion claire.

3. **Gestion des Erreurs** :
   - Les méthodes lèvent des **`IllegalArgumentException`** pour les entrées invalides.
   - Les méthodes retournent **`false`** ou un message d'erreur si une opération échoue.

4. **Extensibilité** :
   - La classe peut être étendue pour ajouter des **permissions**, des **métadonnées** (date de création, taille), ou une **sérialisation** (sauvegarde/restoration de l'état).

5. **Performances** :
   - Les opérations de recherche (`exists`, `isDirectory`, `isFile`) sont en **O(1)** grâce aux `HashMap`.

## **❓ Questions Fréquentes**

### **1. Pourquoi utiliser `Map<String, Set<String>>` pour les répertoires ?**
- **`Map<String, Set<String>>`** permet de :
  - **Stocker chaque répertoire** avec son chemin absolu comme clé.
  - **Associer à chaque répertoire** un ensemble (`Set`) de noms de fichiers/répertoires qu'il contient.
  - **Garantir l'unicité** des noms dans un répertoire (pas de doublons).

### **2. Comment gérer les chemins relatifs ?**
- La méthode `resolvePath()` convertit un chemin relatif (ex: `../parent`) en chemin absolu (ex: `/current/parent`).
- Exemple :
  ```java
  fileSystem.setCurrentDirectory("/a/b");
  String resolved = fileSystem.resolvePath("../c"); // Retourne "/a/c"
  ```

### **3. Pourquoi `normalizePath()` est-elle utile ?**
- Elle **simplifie les chemins** en supprimant :
  - Les `.` (répertoire courant).
  - Les `..` (répertoire parent).
- Exemple :
  ```java
  normalizePath("/a/./b/../c") → "/a/c"
  ```

### **4. Comment ajouter des permissions ?**
- Ajoute un **enum `Permission`** (ex: `READ`, `WRITE`, `EXECUTE`).
- Modifie les classes pour stocker les permissions avec chaque fichier/répertoire.
- Exemple :
  ```java
  private Map<String, Set<Permission>> filePermissions;
  private Map<String, Set<Permission>> dirPermissions;
  ```

### **5. Comment implémenter la sérialisation ?**
- Utilise **JSON** ou **Java Serialization** pour sauvegarder l'état de `FileSystem`.
- Exemple avec **Gson** :
  ```java
  import com.google.gson.Gson;

  public String exportState() {
      Gson gson = new Gson();
      Map<String, Object> state = new HashMap<>();
      state.put("directories", this.directories);
      state.put("files", this.files);
      state.put("currentDirectory", this.currentDirectory);
      return gson.toJson(state);
  }

  public void importState(String json) {
      Gson gson = new Gson();
      Map<String, Object> state = gson.fromJson(json, Map.class);
      this.directories = (Map<String, Set<String>>) state.get("directories");
      this.files = (Map<String, String>) state.get("files");
      this.currentDirectory = (String) state.get("currentDirectory");
  }
  ```
